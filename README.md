### 🛠️ Things I've built

**🔐 [Emotion-Cipher](https://github.com/VijayaY836/Emotion-Cipher)** — *AI-powered secure communication*
Emotion-aware encrypted messaging. DistilRoBERTa reads the *feeling* of a message while AES-256-CBC + PBKDF2 keeps it private — a zero-storage pipeline where nothing is ever kept. `FastAPI · Next.js · HuggingFace · PyTorch`

**🤖 [Multi-Agent Recruitment Screener](https://github.com/VijayaY836)** — *agentic AI, end to end*
A crew of LLM agents that screen candidates collaboratively — orchestrated with LangGraph, each agent owning a stage of the pipeline. Built to explore how far autonomous, cooperating agents can actually be trusted. `LangGraph · Claude · Streamlit`

**📚 [Sourcerer](https://github.com/VijayaY836)** — *RAG document Q&A*
Ask questions, get grounded answers straight from your documents. A retrieval-augmented pipeline built single-origin from the ground up — no CORS gymnastics, just clean architecture. `FastAPI · ChromaDB · fastembed`

**🧩 [Slate](https://github.com/VijayaY836)** — *a programming language, from scratch*
My own language (`.sl`) with a hand-written lexer, a recursive-descent parser, and a tree-walking evaluator. No framework did the heavy lifting — I wanted to understand what happens *underneath*. `Python`

**🗺️ [Cultura](https://github.com/VijayaY836/Cultura)** — *cultural heritage, made interactive*
A living map of Northeast India's 8 states — their languages, festivals, and folktales — with an AI storytelling assistant, multilingual translation, and a handloom marketplace built to genuinely support local artisans. `React · Leaflet · BHASHINI · Web Speech API`

*...and a trail of other things: full-stack productivity platforms, browser-automation agents, and scroll-driven cinematic web experiences. I get bored easily — in the best way.*
